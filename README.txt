جيرون - مشروع أندرويد (النسخة 3.2)

1) الرفع: ارفع الـ ZIP كما هو على موقع بناء APK، JDK 17.
   - «كاملة»: فيها امبد المحلي (Gemma 4). «آمنة»: بدونه (withLlm=false) وبناءها أبسط.
2) supabase-setup.sql: الصقه كله بـ Supabase > SQL Editor > Run (آمن تعيده). يخلي ezksnaruser_ag55 مشرف.
3) الذكاء الاصطناعي الحقيقي لامبد (يقرأ الصور، لغوي ذكي، بدون انتظار): اقرأ supabase/README-AI.txt (5 دقايق).
4) Authentication > Settings: JWT expiry = 604800 حتى تشتغل الإشعارات بالخلفية.
5) رمز الاسترجاع: كل حساب جديد يظهر له رمز استرجاع لمرة وحدة. بدونه، تغيير كلمة السر يضيّع الرسائل القديمة.
6) استرجاع حساب: لوحة الإدارة > استرجاع حساب، أو اكتب لامبد: استرجع حساب البريد@مثال.com
