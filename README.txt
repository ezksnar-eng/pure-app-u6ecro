جيرون - مشروع أندرويد (النسخة 3.3)

1) الرفع: ارفع الـ ZIP كما هو، JDK 17. «كاملة» فيها امبد المحلي، «آمنة» بدونه وبناءها أبسط.
2) supabase-setup.sql بالكامل بـ SQL Editor > Run (آمن تعيده). يخلي ezksnaruser_ag55 مشرف.
3) الذكاء الاصطناعي الحقيقي (اختياري الآن، امبد المحلي يغطي أغلب الحالات مجانًا تمامًا): اقرأ supabase/README-AI.txt.
4) Authentication > Settings: JWT expiry = 604800.
5) القسم الأمني: كلمة سره الافتراضية "امني برو تايم"، تغيّرها من لوحة الإدارة.
6) سجل الأخطاء: لوحة الإدارة > سجل الأخطاء، يعرض آخر 40 خطأ صار بجهاز أي مستخدم فتحه (محليًا على جهازه، انسخه وابعثه لك).
