جيرون - مشروع أندرويد (النسخة 3.1)

الرفع: ارفع الـ ZIP كما هو على موقع بناء APK (settings.gradle بالجذر)، JDK 17.
- AGP 8.2.2، Kotlin 2.2.20، minSdk 26، compileSdk 34.

نسخة «كاملة»: فيها امبد المحلي (Gemma 4 على الجهاز) وتحتاج بناء Kotlin.
نسخة «آمنة»: نفس كل شي بدون نموذج المحلي (withLlm=false بملف gradle.properties) وبناءها أبسط.
إذا فشلت الكاملة: ابنِ الآمنة، أو غيّر withLlm=false بملف gradle.properties.

قبل التشغيل: الصق supabase-setup.sql كله بـ Supabase > SQL Editor > Run (آمن تعيده).
يخلي حسابك ezksnaruser_ag55 مشرف. أدوات قاعدة البيانات صارت داخل لوحة الإدارة فقط.
Authentication > Settings: ارفع JWT expiry إلى 604800 حتى تشتغل الإشعارات بالخلفية.

امبد المحلي: الإعدادات > امبد المحلي > تنزيل النموذج (Gemma 4 E2B حوالي 2.6 جيجا، Apache-2.0). رابطه يتغيّر من الإدارة.
الشبكة القريبة: تشتغل تلقائيًا بعد الموافقة على الأذونات.
