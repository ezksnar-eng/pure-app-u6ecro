جيرون - مشروع أندرويد (النسخة 3.5)

1) الرفع: ارفع الـ ZIP كما هو، JDK 17. «كاملة» فيها امبد المحلي، «آمنة» بدونه.
2) supabase-setup.sql بالكامل بـ SQL Editor > Run (آمن تعيده). يخلي ezksnaruser_ag55 مشرف.
3) إعدادات امبد المحلي والفحص التلقائي صارت داخل لوحة الإدارة فقط، ما تظهر لمستخدم عادي.
4) اختيار نموذج امبد المحلي: لوحة الإدارة > الإعدادات > امبد المحلي: Gemma 4 (افتراضي) أو Qwen2.5 أو رابط مخصص.
   ملاحظة: قراءة الصور محليًا غير مدعومة بعد؛ تبقى عبر بوابة الإنترنت (embed-ai) إذا فعّلتها.
5) Authentication > Settings: JWT expiry = 604800.
