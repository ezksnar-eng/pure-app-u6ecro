جيرون - مشروع أندرويد (النسخة 3.4)

1) الرفع: ارفع الـ ZIP كما هو، JDK 17. «كاملة» فيها امبد المحلي، «آمنة» بدونه.
2) supabase-setup.sql بالكامل بـ SQL Editor > Run (آمن تعيده). يخلي ezksnaruser_ag55 مشرف.
3) الذكاء الاصطناعي عبر الإنترنت (اختياري، امبد المحلي يكفي أغلب الحالات مجانًا): supabase/README-AI.txt
4) Authentication > Settings: JWT expiry = 604800.
5) القسم الأمني: كلمة سره الافتراضية "امني برو تايم"، تتغيّر من لوحة الإدارة.
6) مركز الصور: من القائمة الجانبية، يجمع كل صور محادثاتك ويرفع صور لأي محادثة بدون فتحها أول.
7) الستريك ورسالة لشخص واحد: من لوحة الإدارة.
